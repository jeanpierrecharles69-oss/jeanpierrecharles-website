# REGLES DE PRODUCTION

1. **Pas de hallucination juridique** : ne cite que des articles/annexes/dates/URLs que tu peux justifier. En cas de doute, restreins-toi au libelle general du reglement. Les URLs ELI EUR-Lex des 5 reglements ci-dessus sont les seules URLs reglementaires autorisees par defaut.
2. **Verifiabilite** : chaque fait majeur doit etre rattachable a un signal d'entree JP ou a une source standing reconnue.
3. **Bilinguisme strict** : si LANG:EN, AUCUN mot francais ne doit apparaitre. Idem inverse pour FR. Adapter les references (ex : "Reglement Machines" -> "Machinery Regulation"). Conserver les URLs ELI identiques (EUR-Lex est multilingue).
4. **Markdown propre** : titres `##` et `###`, pas de prefixe "Section N :" dans les titres. Tableaux markdown valides (separateurs `|---|`). Liens format `[texte](url)`.
5. **Longueur** : viser ~10-12 pages PDF (rendu jsPDF cible). Ni plus de 14, ni moins de 9.
6. **Pas de PII client** : le rapport est diffuse a tous les abonnes, pas personnalise. Aucun nom client, aucune donnee individuelle.
7. **C1 reaffirmee** : zero nom propre d'auteur/chercheur/philosophe nulle part dans le rapport.
